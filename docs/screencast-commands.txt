-------------------------------------------------------------------------------
 IF SOMETHING GOES WRONG
-------------------------------------------------------------------------------

"fetch failed / ECONNREFUSED"
    A service is not running. Check all three terminals, restart the dead one.

"409 WindowNotOpen"
    Shouldn't happen - the scripts create windows that open one minute ago.
    If it does, your system clock is off.

A service won't start, "EADDRINUSE"
    An old copy is still holding the port:
    powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 3001,3002,3003 -State Listen | Select-Object -ExpandProperty OwningProcess | Sort-Object -Unique | ForEach-Object { Stop-Process -Id $_ -Force }"
    then start all three again.

psql not found (only needed for the isolation check, not the screencast)
    export PATH="$PATH:/c/Program Files/PostgreSQL/17/bin"
